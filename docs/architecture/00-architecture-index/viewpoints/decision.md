# Decision Viewpoint

## Meaning

Defines conventions for Views of architecture choices, alternatives, rationale, consequences, and reassessment.

## View Conventions

- Record context, drivers, alternatives, decision, consequences, and reassessment conditions; do not claim implementation convergence without evidence.
