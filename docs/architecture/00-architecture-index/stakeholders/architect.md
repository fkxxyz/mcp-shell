# Architect

## Meaning

An architect evaluates and evolves cross-cutting boundaries, contracts, deployment profiles, quality properties, decisions, and architecture risks.

## Boundary

This role is a documentation reader role. It does not grant MCP authorization, repository ownership, or host permissions.
